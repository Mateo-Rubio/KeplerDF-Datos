We have a standard operational tasking that involves a baseline pipeline tracking setup for monitoring the region of Venaco in France. This task requires a multispectral vegetation analysis using the VNIR sensor to assess chlorophyll absorption levels and calculate the NDVI index of the area's surface reflectance. As part of our routine monitoring process, this operation is set within fixed parameters reflecting normal operational status with a workflow update scheduled. It is crucial for data to be delivered in three days in the morning.
